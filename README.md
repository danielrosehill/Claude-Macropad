# Claude-Pad

![Stage: planning / pre-prototype](https://img.shields.io/badge/stage-planning%20%2F%20pre--prototype-orange) ![Type: POC / ideation](https://img.shields.io/badge/type-POC%20%2F%20ideation-blue)

![Claude-Pad banner](assets/banner.png)

A dedicated macropad for driving Claude Code — approve, stop, new session, navigate transcripts — with a host-driven status LED that lights up when Claude is waiting on you.
